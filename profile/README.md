## ![](https://golang.org/favicon.ico)  This is the [golang.design](https://golang.design) initiative. A Go community.

Yes, we are using Go to build developer resources, and we’ve been doing this since Sep, 2020.

## ⚙️ Package and Services

- [golang-design/accel](https://golang.design/s/accel): 🚀 Backend-selectable, cgo-free GPU compute and graphics for Go: a device layer and a tensor layer
- [golang-design/nanogo](https://golang.design/s/nanogo): 🐤 A small Go compiler that aims to compile itself
- [golang-design/ssaplayground](https://golang.design/s/ssaplayground): 🃏 The Go SSA Playground: Exploring SSA IR
- [golang-design/bench](https://golang.design/s/bench): ⏱️ Reliable performance measurement for Go programs
- [golang-design/clipboard](https://golang.design/s/clipboard): 📋 Cross-platform clipboard package that supports accessing text and image in Go
- [golang-design/hotkey](https://golang.design/s/hotkey): ⌨️ Cross-platform hotkey binding package in Go
- [golang-design/x11](https://golang.design/s/x11): 🪟 Minimal pure-Go X11 wire-protocol client (no Cgo, no libX11)
- [golang-design/tgstore](https://golang.design/s/tgstore): An encrypted object storage system with unlimited space backed by Telegram.
- [golang-design/runtime](https://golang.design/s/runtime): 🧰 An extension to the Go runtime package
- [golang-design/reflect](https://golang.design/s/reflect): 🔭 Package reflect implementing the Go proposal [#51520](https://go.dev/issue/51520)
- [golang-design/chann](https://golang.design/s/chann): ✉️ a unified representation of buffered, unbuffered, and unbounded channels in Go
- [golang-design/lockfree](https://golang.design/s/lockfree): ⚡️ Lock-free and wait-free concurrent data structures for Go (generics)
- [golang-design/code2img](https://golang.design/s/code2img): 🖨️ A carbon-now API wrapper and iOS Shortcut
- [golang-design/redir](https://golang.design/s/redir): 🧭 a request redirector

The following packages are now archived but remain available as references. The threading-related ones have been consolidated into [golang-design/runtime](https://golang.design/s/runtime):

- [golang-design/mainthread](https://golang.design/s/mainthread): 🔀 Schedule functions on the main thread in Go — now `runtime/mainthread`
- [golang-design/thread](https://golang.design/s/thread): 🧵 Thread facilities in Go — now `runtime/thread`
- [golang-design/mkill](https://golang.design/s/mkill): ☠️ Limits the number of threads in Go — now part of `runtime`
- [golang-design/go2generics](https://github.com/golang-design/go2generics): 🧪 Experiments about Go 2 generics design
